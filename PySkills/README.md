# Python Projects for Beginners (Bootcamp Approach)

This repository contains my solutions, implementations, and mini-projects completed while working through **"Python Projects for Beginners: A Ten-Week Bootcamp Approach to Python Programming"** by Connor P. Milliken.

The goal of this repo is to track my progress, sharpen my core Python skills, and practice building functional, real-world applications.

---

## 🛠️ Tech Stack & Concepts

* **Language:** Python 3.x
* **Core Concepts:** Data Structures, OOP, File I/O, Error Handling
* **Libraries & Tools:** REST APIs, Web Scraping (`BeautifulSoup`/`requests`), GUI (`Tkinter`), Web Fundamentals

---

## 📅 Weekly Curriculum & Projects

| Week | Focus Area | Key Concepts | Project / Deliverable |
| :---: | :--- | :--- | :--- |
| **01** | Python Basics | Variables, Data Types, User Input | Interactive Terminal App |
| **02** | Control Flow | Conditionals (`if/else`), Loops (`for/while`) | Text-Based Game / Logic Flow |
| **03** | Functions & Scope | Reusable Code, Parameters, Returns | Calculator / Utility Tool |
| **04** | Data Structures | Lists, Dictionaries, Tuples, Sets | Contact Book / Data Manager |
| **05** | Object-Oriented Programming | Classes, Objects, Inheritance | Card Game / Inventory System |
| **06** | File Handling & Errors | `try/except`, File I/O (`.txt`, `.csv`) | Receipt Generator / Log Parser |
| **07** | Modules & Packages | Imports, Virtual Environments | Custom Utility Library |
| **08** | Web Scraping & APIs | HTTP Requests, JSON Parsing | Weather App / Live Data Fetcher |
| **09** | GUI Development | Event-Driven Programming, Layouts | Tkinter Desktop Interface |
| **10** | Web Development Basics | Web Frameworks, Routing | Simple Flask App / Capstone |
